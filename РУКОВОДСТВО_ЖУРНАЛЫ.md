# Руководство пользователя: Журналы приказов

## 🚀 Быстрый старт

### 1. Миграция базы данных (один раз)

Перед первым использованием системы журналов выполните:

```bash
python migrate_add_journals.py
```

Вы увидите:
```
✅ Migration completed successfully!
   Order journal system is now ready to use.
```

### 2. Создание приказа с автоматической регистрацией

1. **Файл → Создать приказ** (или `Ctrl+Shift+G`)
2. Выберите тип приказа
3. **Автоматически появится** следующий номер в подсказке
4. Заполните остальные поля
5. Нажмите **"Сгенерировать приказ"**
6. ✓ Документ создан и зарегистрирован в журнале

### 3. Просмотр журнала

1. Перейдите на вкладку **"Журналы"**
2. Выберите тип журнала в выпадающем списке
3. Установите период (по умолчанию: текущий год)
4. Нажмите **"Применить фильтр"**
5. Просмотрите записи в таблице

## 📋 Основные функции

### Автоматическая нумерация

- **Три независимых журнала:**
  - О зачислении (enrollment)
  - О допуске к аттестации (admission)
  - Об отчислении (graduation)

- **Нумерация:**
  - Начинается с 1 для каждого типа
  - Автоматически увеличивается
  - Система предлагает следующий номер
  - Можно изменить вручную

### Создание приказа

**Автоматический режим (через диалог):**
1. Открыть диалог создания приказа
2. Выбрать тип → видите подсказку: "Следующий номер в журнале: №25"
3. Номер автоматически заполнен (можно изменить)
4. После создания документа → запись автоматически добавляется в журнал

### Ручное добавление записи

**Когда использовать:** для регистрации приказов, созданных вне системы (например, бумажных)

**Как:**
1. Вкладка "Журналы" → **"Добавить запись вручную"**
2. Заполнить форму:
   - Тип журнала
   - Номер (автоматически предложен, можно изменить)
   - Дата
   - Наименование (краткое содержание)
   - Исполнитель
   - Программа (опционально)
   - Примечание (опционально)
3. **"Сохранить"**

### Редактирование записи

**Способ 1:** Двойной клик по строке
**Способ 2:** Правый клик → "Редактировать"
**Способ 3:** Выбрать строку → кнопка "Редактировать"

**Можно изменить:**
- Дату
- Наименование
- Исполнителя
- Программу
- Примечание
- Номер (с проверкой уникальности)

### Удаление записи

**Внимание:** Если к записи привязан существующий файл документа, удаление может быть запрещено.

**Как удалить:**
1. Выбрать запись
2. Кнопка **"Удалить"** или правый клик → "Удалить"
3. Подтвердить удаление

### Фильтрация

**По типу журнала:**
- О зачислении
- О допуске к аттестации
- Об отчислении

**По периоду:**
- Дата "с" и "по"
- По умолчанию: с 01.01 текущего года по сегодня

**Поиск по всем полям:**
- Введите текст в поле "Поиск"
- Поиск ведется по: номеру, наименованию, исполнителю, программе, примечанию

### Экспорт в Excel

**Способ 1:** Вкладка "Журналы" → **"Экспорт в Excel"**
**Способ 2:** Меню "Файл" → **"Экспорт журналов"**

**Формат файла:**
| Номер | Дата | Наименование | Исполнитель | Программа | Примечание |
|-------|------|--------------|-------------|-----------|------------|
| 25    | 12.01.2026 | Приказ... | И.И. Иванов | Программа 1 | ... |

**Экспортируются:** только записи, соответствующие текущим фильтрам

### Открыть документ

**Если к записи привязан файл документа:**
1. Правый клик → **"Открыть документ"**
2. Документ откроется в программе по умолчанию

**Подсветка строк:**
- 🟢 **Зеленый** = приказ создан сегодня
- 🟡 **Желтый** = приказ создан за последнюю неделю
- ⚪ **Белый** = старше недели

## ⚙️ Технические детали

### Структура номера

**Внутри системы:** простой порядковый номер (1, 2, 3, ...)

**В документе:** зависит от шаблона
- Может быть: "25"
- Или с годом: "25/2026"

### Связь с программами

- **Опционально:** можно указать программу при регистрации
- **История:** название программы сохраняется в журнале
- **Если программа удалена:** запись в журнале остается с сохраненным названием

### Уникальность номеров

- Номер уникален **в пределах одного типа журнала**
- Нельзя создать две записи "О зачислении" с номером 25
- Можно иметь: "О зачислении №25" И "О допуске №25" (разные типы)

### Валидация

**При добавлении/редактировании проверяется:**
- ✓ Наличие наименования (обязательно)
- ✓ Номер — число (обязательно)
- ✓ Уникальность (тип + номер)

**При удалении проверяется:**
- ✓ Наличие привязанного файла документа
- ⚠️ Если файл существует, удаление может быть запрещено

## 🎯 Типичные сценарии

2. Выбрать тип "О зачислении"
3. Увидеть: "Следующий номер в журнале: №26"
4. Выбрать 15 слушателей
5. Заполнить программу, даты
6. "Сгенерировать приказ"
7. ✓ Документ создан + запись в журнале

### Сценарий 2: Просмотр всех отчислений за год

1. Вкладка "Журналы"
2. Тип: "Об отчислении"
3. Период: 01.01.2026 - 31.12.2026
4. "Применить фильтр"
5. Просмотр/экспорт

### Сценарий 3: Регистрация бумажного приказа

1. "Журналы" → "Добавить запись вручную"
2. Тип: "О допуске к аттестации"
3. Номер: 15 (предложен автоматически)
4. Дата: 10.01.2026
5. Наименование: "О допуске группы А"
6. Исполнитель: "Иванов И.И."
7. "Сохранить"

### Сценарий 4: Отчет по всем приказам

1. Для каждого типа журнала:
   - Выбрать тип
   - Установить период (весь год)
   - "Экспорт в Excel"
2. Получить 3 файла Excel (enrollment, admission, graduation)

## 🆘 Устранение неполадок

### "Запись с номером №X уже существует"

**Причина:** Пытаетесь использовать уже занятый номер

**Решение:**
1. Используйте предложенный автоматически номер
2. Или выберите другой уникальный номер

### "Не удалось удалить запись (возможно, связан документ)"

**Причина:** К записи привязан существующий файл документа

**Решение:**
1. Удалите или переместите файл документа
2. Или отредактируйте запись, очистив путь к документу

### "Нет данных для экспорта"

**Причина:** Нет записей, соответствующих фильтрам

**Решение:**
1. Проверьте выбранный тип журнала
2. Расширьте период дат
3. Очистите поле поиска

### Миграция не выполнена

**Симптом:** Ошибка при открытии вкладки "Журналы"

**Решение:**
```bash
python migrate_add_journals.py
```
