# Document Generator (AutoWord)

Десктопное приложение для автоматической генерации документов Word на основе шаблонов и базы данных слушателей.

## Возможности

- 📥 Импорт данных из Excel (слушатели и программы обучения)
- 👥 Управление базой данных слушателей с расширенными полями (паспорт, контакты, адреса, СНИЛС, ИНН)
- 📚 Управление программами обучения
- 📄 Генерация документов Word по шаблонам
- 📋 Создание приказов (о зачислении, допуске, отчислении)
- � **Журнал регистрации приказов** с автоматической нумерацией и учётом
- 📝 **Журнал регистрации договоров** с генерацией документов
- 🔤 Автоматическое склонение ФИО по падежам (pymorphy3)
- 💰 **Сумма прописью** для договоров
- 💾 Резервное копирование базы данных
- 📊 Регистрация документов с автоматической нумерацией
- 📤 Экспорт журналов в Excel
- 🔄 **Автоматическая проверка обновлений** через GitHub Releases
- 🌐 Поддержка удалённых баз данных (PostgreSQL, MySQL)
- 🔒 Работает полностью офлайн (для защиты персональных данных)

## Требования

- Python 3.10+
- PyQt5
- SQLAlchemy 2.0+
- pandas
- pymorphy3
- docxtpl

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/VladimirZhilenkov/auto_word.git
cd auto_word
```

2. Создайте виртуальное окружение:
```bash
python -m venv .venv
source .venv/bin/activate  # macOS/Linux
# или
.venv\Scripts\activate  # Windows
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

4. (Опционально) Для удалённых баз данных:
```bash
pip install psycopg2-binary  # PostgreSQL
pip install pymysql          # MySQL/MariaDB
```

## Запуск

```bash
python main.py
```

## Шаблоны Word

Поместите файлы `.docx` в папку `templates/`. Используйте синтаксис Jinja2 для переменных:

### Переменные слушателя — ФИО

| Переменная | Описание | Пример |
|------------|----------|--------|
| `{{ full_name }}` | ФИО (именительный) | Иванов Иван Иванович |
| `{{ full_name_genitive }}` | ФИО (родительный) | Иванова Ивана Ивановича |
| `{{ full_name_dative }}` | ФИО (дательный) | Иванову Ивану Ивановичу |
| `{{ full_name_accusative }}` | ФИО (винительный) | Иванова Ивана Ивановича |
| `{{ full_name_instrumental }}` | ФИО (творительный) | Ивановым Иваном Ивановичем |
| `{{ full_name_prepositional }}` | ФИО (предложный) | Иванове Иване Ивановиче |
| `{{ initials }}` | Инициалы после | Иванов И.И. |
| `{{ initials_before }}` | Инициалы перед | И.И. Иванов |

## Журнал регистрации приказов

### Возможности

- **Независимая нумерация** для каждого типа приказов (зачисление, допуск, отчисление)
- **Автоматическая регистрация** при создании приказов через диалог
- **Ручное добавление** записей для приказов, созданных вне системы
- **Фильтрация** по типу журнала, периоду, свободный поиск
- **Редактирование и удаление** записей с валидацией
- **Экспорт в Excel** в требуемом формате
- **Привязка документов** с возможностью открытия файла из журнала
- **Подсветка записей** (сегодня — зелёный, последняя неделя — жёлтый)

### Использование

1. **Просмотр журнала:**
   - Откройте вкладку **"Журналы"**
   - Выберите тип журнала (О зачислении / О допуске / Об отчислении)
   - Установите период и нажмите **"Применить фильтр"**

2. **Создание приказа с регистрацией:**
   - Меню **Файл → Создать приказ**
   - Номер автоматически предлагается из журнала
   - После создания документа запись автоматически добавляется в журнал

3. **Ручное добавление:**
   - На вкладке **"Журналы"** нажмите **"Добавить запись вручную"**
   - Заполните форму (тип, номер, дата, содержание, исполнитель)
   - Нажмите **"Сохранить"**

4. **Экспорт:**
   - Кнопка **"Экспорт в Excel"** на вкладке "Журналы"
   - Или **Файл → Экспорт журналов**
   - Файл сохраняется с колонками: Номер, Дата, Наименование, Исполнитель, Программа, Примечание

### Миграция для существующих пользователей

Если вы обновляетесь с предыдущей версии, выполните миграцию:

```bash
python migrate_add_journals.py
```

Скрипт добавит таблицу `order_journal` в существующую базу данных.

**Для новых установок миграция не требуется** — все таблицы создадутся автоматически при первом запуске.

## Подключение к удалённой базе данных

Поддерживаются PostgreSQL и MySQL. Настройка через меню **Файл → Настройки базы данных**.

Требуются дополнительные пакеты:
```bash
pip install psycopg2-binary  # PostgreSQL
pip install pymysql          # MySQL
```

## Миграция базы данных

При обновлении с предыдущих версий запустите скрипты миграции:

```bash
# Миграция старых полей (расширенные данные слушателей)
python migrate_db.py

# Миграция системы журналов (новое в v2.0)
python migrate_add_journals.py

# Миграция журнала договоров (новое в v2.0)
python migrate_add_contracts.py

# Миграция продолжительности обучения (новое в v2.1)
python migrate_add_training_duration.py
```

Скрипты безопасны для повторного запуска — проверяют наличие таблиц/полей перед изменениями.
